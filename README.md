# @mourya10104/forecast-charts

[![CI](https://github.com/Mourya10104/forecast-charts/actions/workflows/ci.yml/badge.svg)](https://github.com/Mourya10104/forecast-charts/actions/workflows/ci.yml)

React components for comparing actual and forecast time series: a line chart that plots actual against forecast, and an accessible forecast-horizon slider. Both take their data through props and do no fetching. This package is in development and has not been published to npm yet.
